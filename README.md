#Dashboard de Vendas do XBOX - 2024

Este projeto foi desenvolvido como parte do desafio da DIO, com o objetivo de criar um dashboard em Excel que facilite a visualização e análise de dados de vendas de assinaturas do Xbox ao longo do ano de 2024.

##Visão Geral do Dashboard

O dashboard apresenta os seguintes indicadores principais:

- **Quantidade Total de Inscrições em 2024**: 295
- **Valor Total de Inscrições em 2024**: R$ 7.633,00
- **Faturamento Mensal**: Distribuído mês a mês, permitindo identificar sazonalidades e picos de receita.

##Filtros Interativos

O dashboard conta com segmentações que permitem ao usuário explorar os dados por:

- **Tipo de Console**: Core, Standard, Ultimate
- **Tipo de Assinatura**: Anual, Mensal, Trimestral

Esses filtros tornam a análise mais dinâmica e personalizada, permitindo insights específicos por perfil de produto ou modelo de assinatura.

##Ferramentas Utilizadas

- Microsoft Excel
- Tabelas Dinâmicas
- Segmentação de Dados
- Gráficos Interativos

##Conclusão

Este dashboard foi criado com foco em clareza visual e facilidade de navegação. Ele permite uma análise rápida do desempenho de vendas ao longo do ano, ajudando na tomada de decisões estratégicas.
